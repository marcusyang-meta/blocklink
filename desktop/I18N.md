# Launcher languages

UI language is a client preference, not part of the instance or server config. `src/i18n.tsx` reads the saved choice (or the first system language), sets the document language, and notifies the mounted React app without remounting it. Game selection, searches and modal state are preserved. Dates and numbers use the selected locale.

`src/locales/en.json` maps original Simplified Chinese UI strings to English. Call `t(source, ...values)` with numbered placeholders for dynamic text. Never translate user-entered names, paths, mod IDs, publisher descriptions or game log contents. Module-level category dictionaries keep original text and translate at render time so switching language updates them.

Known service status messages are translated separately. Unknown backend messages preserve the complete original under an expandable Original details control, rather than guessing or concealing the diagnostic information. Game output remains verbatim.

Run `node --test test/i18n.test.mjs` and `pnpm build` after changes. Tests check locale resolution, preservation of interpolated user data, translation coverage and matching placeholders. Test the settings switch in both directions and reload to confirm persistence.
