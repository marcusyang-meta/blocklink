# Default game artwork

`overworld.png` is original generated background artwork, not a screenshot of a user's world. It is bundled locally, so opening the launcher does not fetch remote wallpaper. The library uses different crops of this default cover.

Created with the built-in image generation tool on 2026-09-13. Prompt: cinematic Minecraft-like cubic voxel forest and mountain valley, river and warm timber cabin on the right, sunset amber light and deep green shadows, quiet dark left third for readable interface text, no UI, people, lettering, logos or watermark. Wide composition, central band suitable for a launcher cover.
