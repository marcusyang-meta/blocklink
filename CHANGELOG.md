# Changelog / 更新记录

## 0.1.0 preview — 2026-09-13

- English and Simplified Chinese interface, immediate switching and saved language choice.
- Mod and modpack browsing with categories, compatibility filters and complete-pack imports.
- Separate games, reused mod files, worlds, backups and local server management.
- Native Windows portable build; Linux and macOS build workflows prepared, native validation pending.
- Apple Silicon runtime architecture selection and independent Linux AppImage background host startup.
- Public product website with Chinese/English pages, downloads and privacy information.
