出发前的小问题

现在可以用来做什么？

可以安装游戏环境、管理模组和光影、下载 Modrinth 整合包、导入支持的完整整合包，以及迁移存档和管理本机服务器。当前提供本地玩家模式；微软账户登录仍未完成 Minecraft API 接入，不适用于需要正版验证的服务器登录。

可以安装所有整合包吗？

目前支持 Modrinth 在线安装、.mrpack 和 HMCL / PCL 导出的完整 MCBBS ZIP。CurseForge 在线来源未接入；需要从该来源补齐下载的清单包、任意启动器压缩目录和带自定义启动组件的包暂不支持。

我的存档和账户信息放在哪里？

游戏、模组与存档保存在自己的电脑上。微软登录流程使用系统凭据库保存令牌；房间服务不接收微软登录令牌。联机时会处理房间信息及连接数据，详见隐私说明。

这是 Minecraft 官方启动器吗？

不是。Blocklink 是独立开发的第三方项目，与 Mojang 或 Microsoft 没有隶属、赞助或背书关系。Minecraft 的名称及相关商标归其权利人所有。

可以找到源码和反馈渠道吗？

Blocklink 以 MIT 协议开源。可以查看 源代码、浏览 版本与下载，或通过 GitHub Issues 反馈问题。请附启动器版本、系统和复现步骤，日志中不要包含账户令牌或私人邀请。
