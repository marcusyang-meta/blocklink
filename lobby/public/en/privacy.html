YOUR WORLD, YOUR DATA

Privacy notice

Updated September 13, 2026 · Current development preview

This notice describes how the current version handles data. Blocklink is an independent third-party Minecraft Java Edition launcher. Microsoft account integration is still being verified; Minecraft API access has not been approved.

Data on your computer

Game installations, mods, settings, worlds, backups and launch logs are stored in the local data directory. Windows uses the current user’s application data directory by default. You control migration, backups and deletion in the launcher. Permanently deleting a game installation also deletes its local worlds and backups.

The launcher stores your language choice locally in its interface data. It is not shared with other players through room invitations.

Microsoft sign-in

When you choose Microsoft sign-in, authorization happens on a Microsoft webpage. The app requests Xbox Live sign-in and continued access, and obtains player identity through Microsoft, Xbox and Minecraft services. It does not ask for your Microsoft password in its own form. Refresh tokens and Minecraft access tokens are kept in the system credential vault, not sent to the Blocklink room service. Signing out removes locally saved credentials. You can also revoke access in your Microsoft account’s app permissions.

Finding and downloading content

Online searches and installations contact Mojang/Microsoft, Modrinth, Java distributors and mod loader providers. Search filters, selected versions and ordinary network request information are sent to the relevant service. To identify local mod categories, the app sends SHA-512 file hashes to Modrinth, not mod files, worlds or configuration contents.

Rooms, invitations and multiplayer

Creating a room sends its name, game and loader versions, running state and mod count to the room service hosted on Cloudflare. Joining also involves the name entered by the player, session credentials and connection negotiation data. Rooms expire after 12 hours by default and are cleaned up by scheduled service tasks. Closing a room also clears its associated state.

Invitation links contain information needed to join a room; share them only with people you trust. A relay may be used when a direct connection cannot be established. Network providers process connection and traffic information, such as IP addresses, as needed to deliver the service. The host’s computer runs the server and world. The room service does not receive Microsoft login tokens and is not a cloud backup service for worlds.

This website

Cloudflare provides infrastructure for this website, app downloads and the room service. We have not added advertising, behavioral analytics scripts or third-party tracking pixels. Cloudflare may still process ordinary request information for delivery, billing and abuse prevention; this does not mean that no network-level records exist.

Language choice

The Chinese and English pages use separate URLs. The language switch keeps the current page section where possible. The site does not save this choice in cookies or local storage.

Your controls

You can choose not to sign in with Microsoft, leave multiplayer disabled, close rooms you created, sign out or delete local game data. Shared download caches are managed separately from individual installations; deleting one game may not remove files still reused by others.

Current limitations and contact channels

This is a development preview. Source code and feedback are available in the GitHub repository. GitHub Issues are public: do not post account tokens, private invitations or sensitive data. A dedicated privacy-request email is not available; you control your local data directly. This notice will be updated if data handling changes.
